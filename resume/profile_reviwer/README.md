# Profile Reviewer

Takes the enriched profile and iteratively refines it into a highly professional markdown resume using an AI Actor-Critic loop (Writer & Reviewer).

## Setup

```bash
pip install openai python-dotenv requests
```

Create a `.env` file:
```
MIMO_API_KEY=your_key_here
```

## Run

```bash
python profile_reviwer.py
```
## Inputs

| File | Required | Description |
|------|----------|-------------|
| `input/enriched_profile.md` | Yes | The merged profile generated by the Profile Builder stage |

## Outputs

| File | Description |
|------|-------------|
| `workspace/brief.md` | Strategy brief generated by the Orchestrator Agent |
| `workspace/resume_v{i}.md` | Intermediate resume drafts generated during the iteration loop |
| `workspace/feedback.md` | Strict critiques, modification suggestions, and scores from the Reviewer Agent |
| `output/resume_final.md` | Final optimized resume — ready for submission or PDF conversion |
